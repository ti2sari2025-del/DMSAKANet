# Legacy script (first submission)

`train_dmsa_kanet.py` is the training script of the first submission. It uses image-level five-fold
cross-validation, LR2 = 5e-5, and an 80-epoch schedule, and it selected the threshold on the test fold.
**None of the results in the current manuscript were produced with it.** It is kept only so that the
history of the project remains traceable. Use the scripts in `../training/` instead.
