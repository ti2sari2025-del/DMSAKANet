# Patient-level splits (CDD-CESM)

- `manifest_cddcesm_650.csv` — the 650 included low-energy (DM) images (282 patients): image name, anonymized patient ID, pathology label and quality flags.
- `fold_assignments_cddcesm_650.csv` — patient-level 5-fold cross-validation. `fold` is the outer test fold of each image; `role_fold0` … `role_fold4` give the role (`train` / `val` / `test`) of every image in each outer fold.

No patient appears in more than one role within a fold. The validation patients are drawn from the training folds only and are used for checkpoint selection, learning-rate scheduling and threshold selection; the test fold is used once, for the final evaluation.

Generated by `preprocessing/03_patient_level_split_cddcesm.py` (seed 42). Patient IDs are the anonymized dataset indices of CDD-CESM.
